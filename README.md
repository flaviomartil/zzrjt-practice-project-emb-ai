# Sentiment Analysis practice project

Official IBM course template, completed with synthetic examples for Developing AI Applications with Python and Flask. Uses the course-hosted Watson sentiment model and unchanged provided HTML/JavaScript.

Run inside the authorized Skills Network Theia lab: install requirements.txt, run python3.11 test_sentiment_analysis.py, then python3.11 server.py on port 5000. Static analysis uses pylint 4.1.3 from requirements-dev.txt. No API credential is required by the course endpoint. This is an educational demonstration.
